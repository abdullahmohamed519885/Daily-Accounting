# إصلاح تثبيت تطبيق أذكاري

## ما تم إصلاحه
- إصلاح `manifest.json` واستخدام مسارات نسبية تعمل حتى لو تم نشر المشروع داخل مجلد.
- إصلاح مقاسات وأغراض أيقونات PWA.
- استبدال `service-worker.js` بنسخة واحدة سليمة بدون تكرار `install/activate/fetch`.
- إزالة أكواد PWA المكررة والمتعارضة من `js/app.js`.
- تسجيل Service Worker باستخدام `./service-worker.js`.
- جعل زر التثبيت يظهر فقط عندما يعلن المتصفح أن التثبيت متاح.
- إضافة رسالة مفيدة إذا كان المتصفح لا يدعم نافذة التثبيت.
- تحسين شكل زر التثبيت ليكون احترافيًا ومتجاوبًا مع الهاتف والكمبيوتر.

## مهم
زر التثبيت الحقيقي في Chrome/Edge لا يمكن إجباره من JavaScript. المتصفح هو الذي يقرر متى يرسل `beforeinstallprompt`.

يجب تشغيل الموقع عبر:
- HTTPS في الاستضافة الفعلية.
- أو `localhost` أثناء التطوير.

ولا تعتمد على فتح `index.html` مباشرة من `file://`.

بعد رفع النسخة الجديدة، افتح DevTools > Application وتأكد من:
- Manifest بدون أخطاء.
- Service Workers: الحالة `activated` و Scope صحيح.
- ثم اعمل Hard Reload.

إذا كانت نسخة قديمة من Service Worker موجودة، اضغط Unregister مرة واحدة ثم أعد تحميل الصفحة.

## نافذة التثبيت الاحترافية الجديدة
- استبدال نافذة التثبيت البسيطة بتجربة مخصصة بأسلوب تطبيقات Windows.
- نافذة Modal مع خلفية ضبابية وAnimation ناعم.
- عرض شعار التطبيق واسم «أذكاري» ووصف مختصر.
- عرض 3 مزايا: وصول أسرع، نافذة مستقلة، وتجربة أكثر ثباتًا.
- زر «تثبيت التطبيق» يفتح نافذة التثبيت الأصلية للمتصفح عند توفر `beforeinstallprompt`.
- زر «ليس الآن» وزر إغلاق ويدعم زر `Escape` والنقر على الخلفية.
- حالات واضحة: جاري التثبيت، تم التثبيت، أو التثبيت غير متاح.
- التصميم Responsive للموبايل والكمبيوتر.
- تحديث Service Worker إلى `azkary-v3` حتى تصل تغييرات الواجهة للمستخدمين بعد النشر.
